# ai

AI による集約専用レーンです。人手のメモ（`concepts/` / `relations/` / `learning/` / `sources/`）とは分けて動かし、上書きしません。

## 役割分担

| 場所 | 誰が書く | 目的 |
|------|----------|------|
| `concepts/` など | 人 | 一次メモ・学習ログ |
| `ai/` | AI | 横断集約・関係マップ・差分整理 |

## 構成

```
ai/
  digests/    横断サマリ（日付 or テーマ単位）
  graphs/     関係・関連の整理結果
  proposals/  人手ノートへの追記提案（直接編集しない）
```

## ルール

1. 人手ファイルを直接書き換えない（提案は `proposals/` へ）
2. 根拠のない断定をしない。不明は「未確認」と書く
3. 出典や人手メモへの参照を残す
4. 毎回、前回からの差分が分かるようにする
