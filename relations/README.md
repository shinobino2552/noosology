# relations

概念同士の**関係**と**関連**をここに集約します。

## 記法

| 記法 | 意味 |
|------|------|
| `A → B` | A が B を前提・導く |
| `A ↔ B` | 相互に規定し合う |
| `A ≈ B` | 近い／対比して考える |
| `A ⊃ B` | A が B を含む／上位 |

## 関係一覧

（例）

```text
観測者 → ノウス
ノウス ↔ ロゴス
ψ空間 ≈ 内空間
```

## 追記ルール

- 1行1関係を基本にする
- 根拠やメモがある場合は同じ行の後ろに `# メモ` で付ける
- 概念ノート側の「関連概念」ともなるべく同期する
